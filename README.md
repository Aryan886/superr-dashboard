# SupeRR dashboard

Top 10 batters and bowlers for Rajasthan Royals under pressure, ranked two ways: the Rubric (pure pressure value, 2022-26) and RR fit (players available at the IPL 2027 auction, blended with squad fit).

Static page: `index.html` + `data.js`. The data is generated in the analysis repo with `uv run python -m rr.dashboard` and copied here.
